# Piano Visualizer 🎹

A cross-platform piano visualization application built with Flutter that brings music to life through interactive visual representations.

## Features

- **Real-time Piano Visualization**: Watch as notes are played and visualized in real-time
- **Cross-Platform Support**: Runs seamlessly on iOS, Android, and other platforms
- **Interactive Interface**: User-friendly interface for controlling and viewing piano notes
- **Performance Optimized**: Built with Dart and C++ for fast rendering and smooth animations

## Tech Stack

- **Frontend**: [Dart](https://dart.dev/) (73.1%)
- **Performance Layer**: [C++](https://cplusplus.com/) (13.7%)
- **Build System**: [CMake](https://cmake.org/) (10.3%)
- **iOS Integration**: [Swift](https://developer.apple.com/swift/) (1.4%)
- **Supporting Languages**: C, HTML

## Getting Started

### Prerequisites

- [Flutter SDK](https://flutter.dev/docs/get-started/install)
- Xcode (for iOS development)
- Android SDK (for Android development)
- CMake (for native code compilation)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/avijitsingh5104/Piano-visualizer.git
   cd Piano-visualizer
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Run the application**
   ```bash
   flutter run
   ```
